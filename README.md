# Aplicație simplă pentru gestionarea sarcinilor (To-Do List)

Proiect la disciplina Programare funcțională: o aplicație de consolă în **F#**
pentru gestionarea unei liste de sarcini. Codul și testele sunt în
[`TodoApp/`](TodoApp/).

## Pornire rapidă

Este nevoie de [.NET SDK 10](https://dotnet.microsoft.com/download).

```
cd TodoApp
dotnet run --project src/TodoApp
dotnet test
```

Detalii despre structura codului sunt în [`TodoApp/README.md`](TodoApp/README.md).
